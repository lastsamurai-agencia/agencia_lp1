  画像ファイルの差し替え方法 / Image Replacement Guide
  株式会社AGENCIA - 清掃LP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

このフォルダに下記ファイル名で画像を配置すると、LPに自動的に反映されます。
ファイルがアップロードされていない箇所は、ストライプのプレースホルダーが表示されます。

推奨形式: JPG（写真）/ PNG / WebP / SVG（ロゴ）
推奨サイズ: ヒーロー以外は 1200×900px 程度。容量は1ファイル400KB以下推奨。

────────────────────────────────────────────────────
■ ロゴ（ヘッダー・フッター）
────────────────────────────────────────────────────
  ・logo.svg  または  logo.png
    → 推奨サイズ: 正方形（128×128px〜）/ 透過PNGまたはSVG
    → ヘッダー左上とフッターの "A" マークと自動で差し替わります
    → SVG優先、SVGがなければPNGを読み込みます

────────────────────────────────────────────────────
■ ヒーロー（メインビジュアル）
────────────────────────────────────────────────────
  ・hero-bg.jpg
    → 推奨サイズ: 1920×1200px（横長 16:10）
    → ヒーローセクション全体の背景に表示されます
    → 文字の可読性のため、半透明の白オーバーレイが自動で重なります
    → 配置されていない場合は淡い水色グラデーション背景になります

  ・hero.jpg
    → 推奨サイズ: 1200×1500px（縦長 4:5）
    → 内容: 清潔なオフィス内観 / 清掃中の様子 / ガラス清掃 など

────────────────────────────────────────────────────
■ サービス紹介（8種）
────────────────────────────────────────────────────
  ・service-01.jpg  日常清掃（定期）
  ・service-02.jpg  定期清掃（月1回など）
  ・service-03.jpg  トイレ清掃
  ・service-04.jpg  ガラス清掃
  ・service-05.jpg  カーペット清掃
  ・service-06.jpg  排水管洗浄
  ・service-07.jpg  原状回復
  ・service-08.jpg  スポット清掃
    → 推奨サイズ: 1200×900px（4:3）

────────────────────────────────────────────────────

────────────────────────────────────────────────────

    ・before-03.jpg

  事例04：マンション共用部の床洗浄
    ・before-04.jpg

    → 推奨サイズ: 1200×900px（4:3）

────────────────────────────────────────────────────
■ ファイル合計: 19枚
────────────────────────────────────────────────────
  logo.svg または logo.png                  1枚（ロゴ）
  hero-bg.jpg                               1枚（ヒーロー背景）
  hero.jpg                                  1枚（ヒーロー右側カード）
  service-01.jpg 〜 service-08.jpg          8枚
  before-01.jpg 〜 before-04.jpg            4枚
  after-01.jpg  〜 after-04.jpg             4枚
